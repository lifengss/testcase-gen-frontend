# TestGen 前端业务系统 · 开发计划

> 编制依据：`wiki/` + `需求列表.md`。对齐知识系统 V1.0 里程碑（单人本地完整业务流）。
> 节奏：M0→M5 渐进，每个里程碑可独立验证。

## 里程碑总览

| 阶段 | 目标 | 对应需求 | 关键交付 |
|------|------|----------|----------|
| M0 脚手架 | 工程初始化 | — | Vite+React+TS、BFF(Express)、设计 token、apiClient |
| M1 多项目+上传 | 需求1/2/3 | FR-001~008 | 项目空间、代码/PRD 上传、项目切换器 |
| M2 生成中心 | 需求4 | FR-009~013 | 生成三类型、上下文采集、AI 平台接入 |
| M3 审阅与回写 | 需求5 | FR-014~019 | 草稿审阅台、执行回流、双通路入库、冲突处理 |
| M4 闭环可视化 | 需求4/5闭环 | FR-021/022 | 知识侧栏、图谱、回流看板 |
| M5 打磨 | 需求6 | FR-020 | 科技感 UI 细化、动效、可观测 |

## M0 脚手架（1 周）
- [ ] 初始化 `testcase-gen-frontend`：Vite + React + TS。
- [ ] BFF：Express 骨架 + `KS-Adapter`/`AI-Adapter` 接口占位。
- [ ] 设计 token（深色/玻璃/极光）+ `apiClient`（自动注入 project）。
- [ ] 目录结构按 `架构设计 §5.2` 落地。
- **验证**：启动前后端，`GET /api/projects` 可拉通。

## M1 多项目 + 上传（1.5 周）
- [ ] FR-006/007/008：projectStore + 项目切换器 + localStorage 持久化 + 请求注入。
- [ ] FR-001/002：新建项目（生成 `tg-` ID）→ `POST /api/projects` → `source-upload(type=code)`。
- [ ] FR-003：解析概览展示。
- [ ] FR-004/005：PRD/需求上传（`type=prd/requirement`）+ 资料库列表。
- **验证**：上传代码与 PRD 后，知识系统 `brains/<id>/` 出现对应内容，切换项目不串库。

## M2 生成中心（2 周）
- [ ] FR-012：Context-Harvester 只读采集 D4/B3/D1/B2/B1（并发采集 + 超时）。
- [ ] FR-013：AI-Adapter 抽象 + V1.0 实现（CodeBuddy Agent SDK / OpenAI 兼容）。
- [ ] FR-009/010/011：生成中心三类型，业务意图构造 + 流式返回 + 待审阅区（纯读）。
- **验证**：生成结果显式引用知识来源；换 AI 平台仅改适配层。

## M3 审阅与回写（2 周）
- [ ] FR-014：草稿审阅台 + diff + `POST /api/drafts(source=human_edit)`。
- [ ] FR-015：执行回流（JUnit/pytest XML + JSON 摘要解析）→ `source=exec_backflow` 结构化缺陷。
- [ ] FR-016/017：批量入库（`conflicts/detect`→`batch-commit`）+ 单条入库（显式选项）。
- [ ] FR-018/019：冲突/质量门控提示；无变更操作不写库守卫。
- **验证**：编辑保存→批量确认→D1~D4 出现新知识 + B3 刷新；仅确认状态不入知识库。

## M4 闭环可视化（1.5 周）
- [ ] FR-021：右栏知识上下文（检索用例/脚本/React Flow 图谱）。
- [ ] FR-022：入库看板（缓冲/已入库/回流统计）。
- **验证**：可视化与知识系统状态一致。

## M5 打磨（1 周）
- [ ] FR-020：科技感 UI 细节、动效、玻璃材质、极光强调。
- [ ] NFR-002/003：安全校验、audit 日志、错误边界。
- [ ] 端到端回归：生成→编辑/回流→入库→再生成 全链路。

## 依赖与风险
- **强依赖**：知识系统 V1.0 REST API 稳定（已在 test-knowledge-system 验证端点）。
- **风险1**：AI 平台本地推理时延 → M2 预留流式与降级（纯模板生成）。
- **风险2**：中文 PRD/代码参数拆分 → BFF 调用知识系统保持 `shell:false` + `PYTHONUTF8=1`。
- **里程碑契合**：M1~M3 必须复用知识系统既有 `/api/*`，禁止自建知识落库。
