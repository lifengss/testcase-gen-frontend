# TestGen 前端业务系统 · 需求列表

> 编制依据：`wiki/`（Karpathy LLM Wiki 增量编译）。每条需求标注来源概念/实体，便于追溯。
> 范围：V1.0 单人本地多项目，对齐知识系统 V1.0 里程碑。
> 需求等级：P0 必须 / P1 重要 / P2 增强。

## 1. 功能性需求（FR）

### 1.1 项目与代码接入（用户需求 1）

| 编号 | 名称 | 等级 | 来源 | 说明与验收 |
|------|------|------|------|------------|
| FR-001 | 新建测试项目并上传代码 | P0 | [[entity:测试用例生成前端业务系统]]·需求1 / [[concept:业务端集成模式]]路径B | 上传压缩包(zip/tar(.gz/.bz2/.xz)/7z)或单文件；调 `POST /api/projects` + `POST /api/source-upload(type=code)`；验收：项目出现在 `/api/projects` 且代码已解析、B3 图谱刷新 |
| FR-002 | 自动生成项目 ID | P0 | FR-001 | 前端生成 `tg-<时间戳36><4位随机>` 唯一 ID，建项目时透传；验收：返回 ID 与 `brains/<id>/` 对应 |
