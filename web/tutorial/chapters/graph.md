# 第 8 章 · 知识图谱：可视化依赖

知识图谱把代码间的 **API 调用依赖** 以力导向图呈现，帮助你直观理解模块关系，并直接支撑生成时的「按代码模块」范围。

![知识图谱](/tutorial/assets/graph.png "知识图谱：API 依赖力导向图")

## 8.1 API 依赖图谱解读

- 节点 = 函数 / 模块；边 = 调用关系（谁调用谁）；
- 后台数据驱动自动刷新，切换项目或上传新代码后图谱会更新；
- 悬浮节点可查看其上下游，理清依赖深度。

## 8.2 图谱与生成范围的联动

「生成中心 → 测试范围 → 按代码模块」列出的模块，**正来自这张图谱的真实节点**。因此：

- 图谱里有几个模块，范围里就能选几个；
- 新项目（无代码、无图谱）范围自然为空——这正是第 0 章提到的「不显示 Demo 假模块」改进后的正确行为。

## 案例：在图谱中定位某模块的上下游

1. 打开知识图谱，使用力导向布局找到 `auth` 模块节点。
2. 观察其出边（被谁调用）与入边（它调用了谁），判断改动 `auth` 的影响面。
3. 回到生成中心，测试范围勾选 `auth` 及其直接上游模块，做一次针对性回归生成。
4. 若想聚焦，可在图谱中查看某模块的邻居，再回到生成中心只选这些邻居，避免无关模块干扰。

> 提示：图谱数据是只读视图，不会因你勾选范围而改变；它只反映当前项目已上传代码解析出的真实依赖。
