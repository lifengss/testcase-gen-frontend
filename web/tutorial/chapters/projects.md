# 第 1 章 · 项目空间与多项目管理

TestGen 是**单人本地、多项目**的工作台。每个项目在知识系统 KS 侧拥有独立的 `brains/<id>/` 存储目录，项目之间的草稿、知识库、图谱彼此隔离，互不干扰。

![项目空间](/tutorial/assets/projects.png "项目空间：多项目列表与项目概览指标")

## 1.1 新建项目

点击左上角 **「+ 新建测试项目」** 按钮，填写项目标识（id）与名称即可创建一个独立项目。新建后：

- 侧栏底部「当前项目」会更新为该项目，并显示 `缓冲 N · 冲突 N` 的实时统计；
- 顶部项目标签也会同步；
- 之后所有的生成、草稿、入库、图谱操作都**只作用于当前项目**。

![当前项目与侧栏底部](/tutorial/assets/projects-side.png "侧栏底部「当前项目」实时显示缓冲与冲突数量")

## 1.2 切换 / 选择项目

「项目空间」视图以标签页形式列出全部项目，点击任一标签即可切换当前项目。切换是即时生效的，无需重启任何服务。切换后：

- 生成中心的「测试范围 / 知识上下文」会重新按新项目加载；
- 草稿审阅、入库看板、图谱均只展示新项目的数据；
- 侧栏统计与顶部标签随之更新。

## 1.3 项目概览指标

「项目空间」下方提供项目级概览摘要（由 `loadProjects` 聚合），包括缓冲草稿数、已入库知识页数、缺陷经验数、图谱节点数等，帮助你一眼掌握每个项目的知识沉淀进度。

## 案例：为「订单系统」建立独立项目

1. 点击 **+ 新建测试项目**，标识填 `order-sys`，名称填 `订单系统`。
2. 创建后「当前项目」变为 `订单系统`，侧栏统计显示 `缓冲 0 · 冲突 0`（全新隔离空间）。
3. 后续在生成中心上传订单系统的代码与 PRD，生成的模块、草稿、知识全部落在 `brains/order-sys/` 下。
4. 需要对比时，切回默认项目 `testCaseGenerator`，其数据与 `order-sys` 完全隔离，互不影响。

> 提示：项目隔离是物理隔离（不同 `brains/<id>` 目录）。若误建项目，目前通过 KS 侧管理目录即可；前端暂不直接提供删除入口，避免误删知识资产。
