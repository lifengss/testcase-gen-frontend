# 第 7 章 · 知识检索：关键词与混合语义

知识库沉淀得越多，"找得到"就越关键。知识检索视图让你跨分类检索当前项目已入库的 Brain 知识（质量规则、缺陷经验、项目 Wiki、测试用例等），把历史经验变成下一次决策的依据。

> 说明：本工作台提供的是**知识检索**（关键词 / 混合语义）。KM 系统的**知识问答**（含模型思维链 `<think>` 标签的清理）在 KS 知识系统侧提供，TCGF 不直接承载问答对话界面；若你在 KS 问答中看到未清理的 `<think>` 标签，属 KS 侧渲染问题（已在 KS 反馈修复范围内）。

![知识检索](/tutorial/assets/search.png "知识检索：关键词 / 混合语义模式 + 命中结果")

## 7.1 两种检索模式

检索框下方提供模式切换：

- **关键词（BM25）**：默认模式，本地全文匹配。适合精确查找术语、模块名、接口名（如 `登录`、`鉴权`、`支付`）；
- **混合语义（hybrid）**：关键词 + 向量语义双路检索（本地 BGE 离线模型，无需外网）。适合用**自然语言表达意图**（如"用户密码错误时如何返回错误"）。

> 说明：混合语义命中后结果项会标注「语义命中」徽标，元信息区显示「检索后端：本地 BGE（离线）」。

## 7.2 自动回退

混合语义模式下若无任何命中，系统**自动回退为关键词模式**重试一次，并在结果元信息区提示「语义无命中，已自动回退关键词」，避免给你一个空结果页。

## 7.3 结果与后续动作

- 每条结果展示命中页标题、分类与相关片段，按相关度降序排列；
- 结果只读浏览；若要补充 / 修改知识，仍走「草稿审阅 → 入库看板」的闭环。

## 案例：用一句话找到历史缺陷经验

1. 打开「知识 → 知识检索」，模式切到 **混合语义**。
2. 输入"用户登录时密码错误多次导致锁定"。
3. 系统返回该意图下最相关的缺陷经验与质量规则条目，其中语义命中项带徽标。
4. 若换一个无任何语义命中的词，系统自动回退关键词模式并提示，仍能给出基于全文匹配的结果。

> 提示：检索只覆盖**当前项目**知识库；换项目后命中范围随之切换。
