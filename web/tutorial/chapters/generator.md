# 第 3 章 · 生成中心：智能生成测试用例

生成中心是 TestGen 的核心。你在这里声明「要生成什么、覆盖哪里、用什么框架」，系统基于当前项目的知识上下文调用 AI 平台产出结果。

![生成中心配置区](/tutorial/assets/generator.png "生成中心：生成配置 + 文档材料 + 流式输出")

## 3.1 三种产物

顶部「生成配置」的第一个分段切换产物类型：

- **大纲**：测试用例大纲（章节 / 场景划分），适合先对齐测试思路；
- **条目**：具体测试用例条目（标题 + 步骤 + 预期），最常用；
- **脚本**：可直接运行的自动化脚本（按所选框架生成）。

## 3.2 测试范围

「测试范围」提供两种维度，可配合「全选所有模块」一键勾选：

- **按业务模块**：来自业务流依赖图谱（`/api/business-graph`）的真实业务域（新项目为空，需先在「知识图谱」页生成业务图谱）；
- **按功能模块**：来自 PRD / 需求列表解析出的功能模块。

勾选的模块会作为生成时的重点覆盖对象。

## 3.3 测试深度、框架与约束

- **测试深度**：`冒烟`（核心链路快速验证）/ `全量`（完整覆盖，含异常分支）；
- **自动化框架**：`pytest (Python)` / `JUnit5 (Java)` / `Jest (TS)`，仅在选择「脚本」产物时影响输出形态；
- **约束 / 备注**：自由文本，例如「覆盖异常分支与幂等性，业务流依赖关系以图谱为准」，会注入生成提示词。

## 3.4 知识上下文面板

右下角「知识上下文（只读）」实时显示当前项目可用知识量（历史用例 / 自动化脚本 / 图谱节点），生成时 AI 会据此检索命中参考，使新用例继承既有经验。

## 3.5 生成与保存

点击 **「⚡ 生成测试用例」** 后，右侧流式区域实时输出。完成后：

- **＋ 保存到草稿**：把结果写入当前项目的草稿箱（来源标记生成）；
- **⬇ Markdown / ⬇ PDF**：下载到本地。

## 案例：为 `auth` 模块生成冒烟用例

1. 在生成中心，产物选 **条目**，测试范围切到 **按业务模块**，勾选目标业务域（若为空请先在「知识图谱」页生成业务图谱）。
2. 深度选 **冒烟**，框架选 **Pytest**，备注填「覆盖登录失败与 token 过期」。
3. 点击 **生成测试用例**，观察流式输出。
4. 结果满意后点 **＋ 保存到草稿**，到「草稿审阅」即可看到这条新草稿（来源标记 `human_edit`）。
5. 若想进一步变脚本，把产物切到 **脚本** 重新生成即可。

> 提示：AI 偶发短响应会被质量门控拒收（结构化 Markdown 内容过短）。若生成结果异常短，可重试或调大 CodeBuddy 的 `maxTurns`。
