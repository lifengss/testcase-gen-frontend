# 实体：测试用例生成前端业务系统（TestGen）

> 项目代号：`testcase-gen-frontend`
> 来源：[[source-summary:架构设计与技术方案]]
> 关联：[[concept:业务端集成模式]] · [[concept:三层Prompt分离]] · [[concept:知识闭环数据流]] · [[concept:多项目隔离]] · [[entity:知识系统API契约]]

## 定位
知识系统（test-knowledge-system）的**外部业务前端**，承载「自动化测试用例生成」全部用户交互与业务编排逻辑。是知识系统架构中「业务侧」的具体实现。V1.0 对齐单人本地多项目里程碑。

## 分层
- **前端应用层**（React + Vite + TS）：projects / upload / generator / review / backflow / commit / context 七大 feature。
- **后端编排层 BFF**（Node/Express）：KS-Adapter（知识系统适配）、AI-Adapter（AI 平台适配）、Intent-Orchestrator（意图编排）、Context-Harvester（上下文采集）、Writeback-Orchestrator（回写编排）。

## 不做什么（边界）
不重建 AI harness（工具/对话/上下文/大模型调用交给 AI 平台）；不重建知识存储（落库全经知识系统）；不做团队协同/权限（V2.0+）。

## 六需求 → 模块映射
| 需求 | 模块 | 路径 |
|------|------|------|
| 1 上传代码+项目ID | upload + KS-Adapter | B |
| 2 上传PRD/需求 | upload（type 区分） | B |
| 3 多项目 | projects + projectStore | B |
| 4 生成大纲/条目/脚本 | generator + Context-Harvester + AI-Adapter | A |
| 5 回写闭环 | review + backflow + commit + Writeback-Orchestrator | B |
| 6 科技感UI | components + styles（深色/玻璃/极光） | — |

## UI 设计基调（需求6）
近黑深空基底 `#0B0E14` + 极光青→品紫渐变 `#22D3EE→#A855F7`；玻璃拟态面板；等宽数据字体；左导航+中工作区+右知识侧栏（2:6:3）；图谱用 React Flow 力导向。禁用高饱和纯色按钮与默认阴影。
